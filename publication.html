02 / ПРИВАТНОСТЬ И ХРАНЕНИЕ

Минимум данных и ограниченный срок хранения

Публичная поверхность статична: нет аккаунтов, форм ввода, пользовательского профиля, внешней аналитики, рекламных пикселей или cookies для отслеживания.

Пользовательские данныеНе собираются

Сайт не принимает личные сведения и не сохраняет введённые пользователем значения.

АналитикаОтключена по решению продукта

До появления отдельной задачи и правил согласия QAZ не заявляет посещаемость, конверсию или удержание.

ВыпускиАктивный + 7 предыдущих

Неизменяемые деревья хранятся для отката; сервер также сохраняет восемь последних резервных копий QAZ-конфигурации.

Мониторинг7 дней

Артефакт ежедневной проверки публичных контрактов хранится семь дней и не содержит закрытых данных.

эксплуатационные решения

Выпуск без скрытого состояния.

Отдельного staging-домена нет. Принятый процесс проверяет локальный артефакт и кандидата Caddy до атомарного переключения текущего выпуска; при ошибке предусмотрен откат.

Открыть статус выпуска ↗
  1. 01Владелец продукта

    Владелец репозитория QAZ.INDUSTRIES отвечает за проекции, выпуск и решения о публикации.

  2. 02Владелец runtime

    Оператор общего public-sites Caddy отвечает за доступность прокси и VPS; инцидент должен явно называть границу QAZ.

  3. 03Исправление

    Ошибка исправляется в источнике или проверенной проекции и выходит новым неизменяемым выпуском с датой и идентичностью.

  4. 04Удаление из публикации

    Спорный или чувствительный материал исключается из текущего выпуска; предыдущие деревья доступны только оператору для ограниченного отката.

03 / БЕЗОПАСНОСТЬ

Не раскрывать уязвимость публично

Сообщение должно содержать URL, минимальное воспроизведение и влияние, но не учётные данные и не закрытые записи. Публичный issue для уязвимостей не используется.
