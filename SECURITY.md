# Security policy

Do not publish a suspected vulnerability as a public issue. Submit a private
report through [GitHub Security Advisories](https://github.com/belilovsky/qaz-industries/security/advisories/new)
and include the affected URL, a minimal reproduction, and the impact. Do not
include credentials or private records.

The public surface is intentionally static. Reports concerning the shared
proxy, VPS access, or another portfolio product must name that boundary so they
can be routed without exposing unrelated infrastructure.

GitHub private vulnerability reporting is enabled for this repository. It is
the stable public-facing intake route; no public security mailbox is needed.
Never place vulnerability details in a public issue.
